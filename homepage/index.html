Repository-native development workflows

Git and committed repository files stay the source of truth. Zendev checks commits, pull-request messages, proposals, and project evolution.

uvx zendev --help

Add it to a project from Getting started. Python 3.12 or newer.

Four checks

  • Commits

    Create a commit with the repository's message profile.

    zendev commit Commit guide

  • Messages

    Check a title, a commit message, or a pull-request body.

    zendev message check Message checks

  • Proposals

    Validate durable proposal records and their index.

    zendev proposal check Proposal guide

  • Evolution

    Check the initial intent and dated changes in EVOLUTION.md.

    zendev evolution check Evolution guide

What the repository keeps

The repository keeps its terminology, templates, schemas, and governance decisions. Zendev validates that record.
