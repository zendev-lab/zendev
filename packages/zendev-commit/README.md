# zendev-commit

`zendev-commit` provides Zendev, Conventional Commits, and Gitmoji profiles,
complete commit-message validation, and the interactive commit workflow.

```console
$ uvx --from zendev-commit zendev-commit --help
$ uvx --from zendev-commit zendev-commit-msg --help
```

The complete `zendev` distribution depends on this component and exposes the
same workflows under its unified command.
