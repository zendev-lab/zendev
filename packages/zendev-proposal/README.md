# zendev-proposal

`zendev-proposal` validates and indexes repository-native proposal processes.
Repositories keep their schemas, templates, lifecycle policy, and decisions;
the tool provides reusable mechanics and stable diagnostics.

```console
$ uvx --from zendev-proposal zendev-proposal --help
```

The complete `zendev` distribution depends on this component and exposes the
same commands under `zendev proposal`.

See the [complete documentation](https://github.com/zendev-lab/zendev/blob/main/docs/proposals.md)
for policy configuration and command behavior.
