# zendev-evolution

Read, write, and validate a single `EVOLUTION.md` containing a project's
initial intent and dated changes in direction.

```shell
uv add --dev zendev-evolution
uvx zendev-evolution --help
```

The complete toolkit exposes the same commands as `zendev evolution`.
See the [Evolution guide](https://docs.zendev.zrr.dev/guides/evolution/)
for the document format, commands, and migration examples.
