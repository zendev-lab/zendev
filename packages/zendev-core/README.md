# zendev-core

Shared configuration discovery, structured diagnostics, operation-scoped source
snapshots and Markdown facts. Core has no dependency on the CLI or domain packages.

```shell
uv add zendev-core
```

See the [architecture](https://docs.zendev.zrr.dev/development/architecture/) and
[configuration reference](https://docs.zendev.zrr.dev/reference/configuration/).
