# Zendev Feature Proposals

ZFPs are lightweight, durable decisions for public zendev features. Read
[ZFP-0000](./ZFP-0000-governance.md) before proposing or implementing a feature.

The committed [index](../zfps-index.json) is generated from proposal
frontmatter. Check it with:

```console
$ uv run zendev-proposal check
$ uv run zendev-proposal index --check
```
