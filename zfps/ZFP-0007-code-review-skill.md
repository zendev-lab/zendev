# ZFP-0007: 可复用的代码审查 Skill

## 摘要

在 `skills/code-review/` 提供独立的 Agent Skill，指导 Agent 对指定代码变更
进行有证据的审查。消费仓库继续拥有行为契约和审查策略。

## 动机

消息格式校验不能判断实现是否正确。当前 `zendev-review` 负责消息校验，
代码审查则需要明确范围、追踪调用关系、验证候选问题并过滤误报的可复用指导。

## 设计

Skill 使用标准 `SKILL.md` 入口，按需加载审查示例和设计来源。覆盖 PR、
commit range 及本地改动；默认只读，在对话中报告，不自动修复或发布评论。
每项 finding 给出位置、触发条件、违反的契约、影响和修复方向。
严重程度与证据可信度分别判断；没有发现不代表证明不存在缺陷。

正文保持模型无关，不固定模型、推理等级、子代理数量或外部服务。
以 Git 仓库中的目录分发，文档说明如何复制完整目录或显式读取入口。
不新增 CLI、Python API、配置或自动安装机制，不改变已有包边界。

## 兼容性

该 Skill 是可选指导，不替代消费仓库规则、CI 或人工合并决策。
安装 Python 包不会自动安装 Skill；已有 CLI 和消息校验行为保持兼容。

## 验证

检查入口元数据、相对引用及文档构建，并运行现有仓库检查。
保存包含真实回归、上下文排除误报和信息不足的审查案例，比较使用 Skill
与未使用 Skill 的输出；记录实际发现和漏报，不以格式检查替代审查质量评估。
